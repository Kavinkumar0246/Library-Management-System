## ✨ Features

- 📖 Add and manage books
- 🔍 Search books easily
- 📥 Issue books to students
- 📤 Return book management
- 📢 Library announcements
- 🌐 E-Resources access
- 👨‍🎓 Student access
- 👩‍🏫 Librarian access
- 🔐 Admin dashboard

---

## 👥 User Roles

| Role | Access |
|------|---------|
| Student | Browse and issue books |
| Librarian | Manage library records |
| Admin | Full system control |

- HTML
- CSS
- PHP
- MySQL

## 🚀 Future Enhancements

- Online book reservation
- QR-based issue system
- Email notifications
- AI-based book recommendations

## 📌 Project Objective

This project aims to simplify library management by digitizing book records, issue/return tracking, and user management.
